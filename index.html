비용 절감 및 설계 최적화

동적 아키텍처 설계를 통한 외주 시스템 내재화

문제 상황 (Problem)

이도 재직 시절, 사내 핵심 지점별 시스템 관리가 외주 의존형으로 구성되어 있어 연간 약 2,000만 원 상당의 비효율적인 유지보수 비용이 지속적으로 유출되고 있었으며, 각 현장 관리자가 중복된 데이터를 직접 수동 입력해야 하는 불필요한 반복 업무 리스크가 상존했습니다.

원인 분석 (Analysis)

전국 사업장별로 데이터베이스 구조와 세부 비즈니스 처리 프로세스가 파편화되어 있었습니다. 게다가 공공기관 EDI 문서 규격과 현장 로컬 데이터 간의 자동 연동 파이프라인이 부재하여 중복 연산 및 비효율이 발생하고 있었습니다.

해결 접근 (Solution)

  1. 팩토리(Factory) 및 전략(Strategy) 패턴 도입: 지점별 상이한 처리 비즈니스 로직을 동적으로 로드 및 주입할 수 있는 유연한 구조 설계.
  2. 동적 엔티티 주입(Entity Injection): 하나의 통합 코드베이스 내에서 현장별 엔티티 구성을 수용하도록 개편하여 코드 재사용성 극대화.
  3. EDI 스펙 문서 연동 자동화: 현장 데이터 자동 동기화 팩토리 모듈을 자체 개발하여 중복 데이터의 원천적 차단.

성과 및 수치 (Result)

  • 비용 절감: 자체 개발 및 내재화를 완수하여 **연간 약 2,000만 원의 유지보수 비용 절감**
  • 업무 효율성: 지점별 수동 입력 단계를 원천 제거하여 담당 실무자의 생산성 및 만족도 대폭 향상
  • 확장성 확보: 새로운 지점 요구사항 추가 시 기존 코드 변경을 최소화하고 전략 클래스 추가만으로 대응 가능

브랜드 디렉터의 한 마디 (Review)

"현장을 직접 방문해 수동 업무의 비효율을 진단하고, 디자인 패턴을 적용해 구조적 문제를 해결한 최고의 소프트웨어 엔지니어링 사례입니다."

백엔드 성능 튜닝

150만 건 대용량 출입 통계 API 쿼리 최적화

문제 상황 (Problem)

사용자가 늘어남에 따라 일일 출입 통계 조회 API의 응답 속도가 2초 이상 지연되어, 인하우스 서비스 사용자 및 고객사로부터 속도 지연에 대한 컴플레인이 다수 접수되었습니다.

원인 분석 (Analysis)

Pinpoint APM을 활용해 호출 병목 구간을 탐지한 결과, 약 150만 건의 누적 로그 데이터를 조회할 때 인덱스가 유실되어 Full Table Scan을 타고 있었으며, 불필요하게 엮인 다중 Join 연산이 실행 계획 수준에서 많은 부하를 주고 있음을 찾아냈습니다.

해결 접근 (Solution)

  1. 데이터 카디널리티 분석 및 복합 인덱스 설계: 데이터의 선택성(Selectivity)을 분석하여 `[학교 ID - 날짜 - 학생 ID]` 결합 순서의 복합 인덱스 생성.
  2. SQL 튜닝 및 서브쿼리 개편: 과도한 전체 조인 연산을 걷어내고 드라이빙 테이블 범위를 인덱스 스캔 범위 내로 축소하도록 유도하는 서브쿼리 및 인라인 뷰 최적화.

성과 및 수치 (Result)

  • 응답 속도 개선: 쿼리 평균 응답 속도 **2.0s → 0.1s 미만 단축 (약 95% 성능 향상)**
  • 서버 부하 감소: 데이터베이스 I/O 리소스 점유율 감소로 전체 통계 배치 서비스의 안정성 증대

브랜드 디렉터의 한 마디 (Review)

"단순히 쿼리를 동작시키는 것을 넘어 실행 계획을 열어보고 병목을 정밀 타격한 튜닝 역량의 정수를 보여줍니다."

보안 및 CI/CD 프로세스

Shannon Entropy 알고리즘 기반 API Key 유출 탐지 스크립트

문제 상황 (Problem)

개발 편의를 위해 소스 코드 내부에 서드파티 서비스 API Credential Key가 하드코딩된 채 형상 관리에 업로드될 위험이 존재했으며, 단순 정적 코드 리뷰만으로는 수많은 소스 내 난수 형식의 키를 완벽히 모니터링하기 힘든 보안 공백이 있었습니다.

원인 분석 (Analysis)

정적인 파일 매칭 검사는 정규표현식 매칭 오류가 잦고, 무작위 난수 형태로 생성되는 고유 암호키의 특성을 잡아내기 어려웠습니다. 이에 스트링의 복잡도와 무작위성을 정량화할 수학적 측정 방식이 요구되었습니다.

해결 접근 (Solution)

  1. Shannon Entropy 기반 분석기 작성: 특정 문자열의 정보 복잡도를 계산하는 Shannon Entropy 알고리즘을 활용한 Python 스크립트 작성.
  2. 검증 파이프라인 통합: 팀 내 5개 공통 리포지토리의 보안 리뷰 머지 단계에서 자동으로 소스 내의 위험 텍스트를 감지하도록 CLI 훅 형태로 설정.

성과 및 수치 (Result)

  • 실제 탐지: 탐지 도구 적용 직후, 코드에 하드코딩되었던 테스트용 API Key **2건 추가 발견 및 제거**
  • 보안 수준 제고: 소스 코드 유출로 인한 2차 자산 위협 가능성을 제로에 가깝게 차단하여 사내 컴플라이언스 준수

브랜드 디렉터의 한 마디 (Review)

"보안 위협이 단순한 실수로 이어지지 않도록 수학적 모델을 적용해 파이프라인을 구축한 훌륭한 자동화 솔루션입니다."

UX & 프론트엔드 최적화

웹 리소스 최적화 및 LCP 개선을 통한 이탈률 감소

문제 상황 (Problem)

사진 리스트와 다양한 리소스가 밀집된 지점 갤러리/소개 페이지의 체감 속도가 느려, Google Analytics 분석 결과 특정 로딩 시점에서 유입 유저의 비정상적 이탈이 다수 감지되었습니다.

원인 분석 (Analysis)

Lighthouse 분석 측정 결과 **LCP(Largest Contentful Paint) 지표가 3.5초**로 저하되어 있었습니다. 원인은 초기 랜더링 시 무거운 PNG/JPG 이미지 에셋들이 브라우저 커넥션을 일시에 선점하며 메인 스레드를 블로킹했기 때문이었습니다.

해결 접근 (Solution)

  1. WebP 이미지 컨버전: 기존 정적 리소스를 품질 손실 없이 50%~70% 이상 용량이 경량화된 WebP 포맷으로 변환.
  2. 지연 로딩(Lazy Loading) 적용: 브라우저가 화면을 그릴 때 스크롤 뷰포트에 감지된 이미지만 로드되도록 **Intersection Observer API**를 적용하여 레이아웃 효율화.

성과 및 수치 (Result)

  • 로딩 지표 개선: LCP 시간을 **3.5초에서 2.1초로 단축 (약 40% 성능 향상)**
  • 비즈니스 지표 개선: 페이지 진입 초기 이탈 현상이 해결되며 **최종 유저 이탈률 약 15% 감소**

브랜드 디렉터의 한 마디 (Review)

"단순 개발에 그치지 않고 구글 애널리틱스 지표를 읽고 비즈니스 개선 효과까지 이끌어낸 풀스택 엔지니어링의 본보기입니다."
